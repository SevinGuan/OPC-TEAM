# 人格 → 设计 Token 映射表

用途：把访谈收集到的通俗答案翻译成可执行的设计参数。**对小白展示时必须使用"反向翻译"列的语言。**

## 一、人格 → 设计 Token

| 人格 | 色板 | 字体 | 密度 | 圆角 | 动效 | 反向翻译（对小白这么说） |
|---|---|---|---|---|---|---|
| 热情的销售高手 | 高饱和主色 + 暖色点缀，明快 | 醒目的粗标题，字号偏大 | 中低密度，重点突出 | 大圆角 12-16px | 丰富：进场动画、hover 弹跳 | "页面很精神，颜色亮堂，东西会跟你互动，让人有劲" |
| 冷静的教授 | 低饱和，一两个主色，大量留白 | 衬线标题（宋体/衬线英文），正文舒适 | 低密度，一段一段讲清楚 | 小圆角 4-8px | 极少，只有淡入淡出 | "页面很安静，像一本排版好的书，不催你，让你慢慢看" |
| 犀利的操盘手 | 黑/深灰底 + 单一强调色（如红），涨跌色分明 | 无衬线硬朗字体，等宽数字 | 高密度，一屏多列 | 小圆角 2-6px | 只服务数据：数字滚动、闪烁 | "一屏全是关键信息，没有一句废话，眼睛扫到哪数据就在哪" |
| 温和的图书管理员 | 柔和米白/浅灰底，低对比舒适色 | 圆润无衬线 | 中等，分类整理清晰 | 中圆角 8-12px | 轻柔过渡 200-300ms | "看着不累，东西都分好类放在该在的地方，找什么都顺手" |
| 前卫的艺术家 | 大胆撞色或极端单色，深浅拉满 | 超大号标题，可能用艺术字体 | 两极：要么极空要么爆炸 | 两极：直角或超大圆角 | 强烈：滚动视差、3D、鼠标跟随 | "第一眼就被震住，跟别的网站都不一样，看过就忘不掉" |
| 靠谱的工程师 | 中性灰阶 + 一个克制的品牌色 | 系统无衬线，层级分明 | 中高密度，对齐严谨 | 统一 6-8px | 精确短促 150-200ms | "每个像素都有理由，对齐、等距、工整，看着就放心" |

## 二、场所隐喻 → 密度与动效

| 场所 | 密度 | 动效 | 反向翻译 |
|---|---|---|---|
| 安静的书店 | 低，大留白 | 几乎没有 | "慢慢逛，每个角落都留了呼吸的空间" |
| 热闹的夜市 | 高，色彩多 | 丰富频繁 | "信息琳琅满目，到处都吸引你停下来看" |
| 精密的驾驶舱 | 高，但分区严格 | 精确、快速 | "东西多但一点都不乱，每个仪表都在固定位置" |
| 精品买手店 | 低-中，每个单品都有舞台 | 精致克制 | "一次只让你看几件好东西，但件件是主角" |
| 便利店 | 中高，分类清晰 | 无 | "要什么直接奔哪个货架，拿了就走，高效" |

## 三、专业术语 → 通俗语言对照（反向翻译表）

对小白解释设计决策时使用右列语言，严禁出现左列词汇：

| 专业术语 | 通俗说法 |
|---|---|
| 高对比配色 | "颜色深浅拉得很开，重要的东西一眼跳出来" |
| 低饱和度 | "颜色不艳、不刺眼，像蒙了一层灰的质感" |
| 信息密度高 | "一屏塞进更多信息，像交易软件那样满满当当" |
| 留白 | "页面故意留空，让重点更突出、看着不累" |
| 视觉层级 | "东西有大有小、有先有后，先看最重要的" |
| 圆角 | "盒子边角是圆润的还是方正的" |
| 动效/微交互 | "鼠标放上去、点击时的小反应" |
| 无衬线字体 | "笔画一样粗的现代字体，屏幕上最清楚" |
| 衬线字体 | "笔画有粗细变化的传统字体，像报纸书刊" |
| 等宽数字 | "每个数字占一样的宽度，对得整齐，适合看数据" |
| 响应式 | "手机和电脑打开都各自好看" |
| 设计 token | "一套统一的颜色、字体、间距规则" |
| 暗色主题 | "黑底或深灰底，晚上看不刺眼" |

## 四、参照物分析方法

拿到用户提供的参考网站/截图后，按此顺序提取特征：
1. **底色与主色**：亮/暗？主色是什么？有几个颜色？
2. **密度**：首屏有几个信息块？
3. **字体气质**：标题是衬线还是无衬线？粗细？字号夸张吗？
4. **圆角**：卡片是方是圆？
5. **动效**：有动画吗？克制还是张扬？
6. **层级手法**：用颜色、字号还是位置区分主次？

提取结果作为最高权重的风格依据，直接进入 brief 生成；与用户前几问的答案冲突时，以参照物为准并向用户说明。
