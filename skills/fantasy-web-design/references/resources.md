## 模块二：UI 组件库（开源）

- **shadcn/ui** — ui.shadcn.com — 85k★，2026 事实标准。组件代码复制进项目、100% 归你。Radix 无障碍原语 + Tailwind。dashboard/后台/SaaS 首选打底
- **Tremor** — tremor.so — 数据仪表盘专项，自带图表、指标卡、数据表格
- **Magic UI** — magicui.design — 15k★ 增速快。数字滚动、流光按钮、动画列表
- **Aceternity UI** — ui.aceternity.com — 28k★。"Vercel/Linear 质感"，3D 卡片、聚光灯。偏营销页，行情页慎用
- **HeroUI**（原 NextUI）— heroui.com — v3 支持 Tailwind 4，出厂设计感更成品
- **React Bits** — reactbits.dev — 高质感动效组件复制粘贴库
- **21st.dev** — 21st.dev — shadcn 组件注册表社区，找冷门组件
- **DaisyUI** — daisyui.com — 零 JS，35 套主题，适合静态页
- **Tailwind Plus**（原 Tailwind UI，付费）— tailwindcss.com/plus — 官方模板库 ~$300 买断

通行组合：shadcn/ui 打底 + Tremor 数据可视化 + Magic UI 动效（同为 Tailwind 栈，无缝混用）。
