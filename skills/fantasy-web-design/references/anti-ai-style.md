# 去 AI 感设计规范

"AI 感"不是玄学，是五个可识别的特征。任何产出（页面、文档、brief）逐条自查。

## 五条铁律

### 1. 禁：大面积紫色→蓝色渐变背景 + 毛玻璃卡片
- 替代：单色或克制的双色方案；玻璃拟态效果全页最多出现一处
- 理由：这是 AI 生成页面的第一特征，一眼假

### 2. 禁：居中排版 + 超大圆角 + 每个卡片配 emoji 图标
- 替代：以左对齐为主（符合阅读动线）；圆角遵循 brief 设定（通常 4-14px）；图标一律用 Lucide/Phosphor 线性图标库，不用 emoji 充当图标

### 3. 禁："✨ 强大 · 智能 · 高效"式空话文案
- 替代：写具体——什么数据、什么结论、给谁看、看完能干什么
- 例：不写"智能分析引擎"，写"3 秒看懂今天涨停主线"

### 4. 禁：所有卡片同尺寸、等距排列，没有信息层级
- 替代：有主次。核心指标大、次要信息小；用字号（至少 3 级）、字重、颜色、留白四个维度拉开层级；关键数字要成为视觉锚点

### 5. 禁：默认字体 + 千篇一律的 hero 区（大标题+副标题+两个按钮）
- 替代：按 brief 精选字体搭配；首屏直接进正题/进数据，不做仪式感铺垫

## 自查清单（产出前过一遍）

- [ ] 有渐变背景吗？超过一处玻璃拟态吗？
- [ ] 有 emoji 当图标用吗？
- [ ] 文案里有"赋能/强大/智能/高效/一站式"这类空词吗？
- [ ] 首屏的信息块大小全部一样吗？
- [ ] 字体是浏览器默认黑体到底吗？
- [ ] 标题居中、正文居中、按钮居中的"三居中"结构吗？
- [ ] 颜色超过 4 种主色吗？

任一项命中 → 修改后再交付。

## 正例参照

- Linear (linear.app) — 暗色克制的标杆
- Stripe (stripe.com) — 层级与留白的标杆
- FT / 财新 — 编辑排版的标杆
- TradingView — 数据密度的标杆
- 用户已认可的「无 AI 感」基线（随包参考，不指向任何本机路径）：左对齐、三级字号、无渐变、无 emoji 图标、单一强调色 #FF4D4F
