# 4_非功能需求

> 按 ISO/IEC 25010 质量模型 + 商业级项目标准。每条非功能需求应**可度量**（有目标值 / 阈值），不可度量的一律标「待定 + 理由」。

## 性能（Performance）
- 响应时间（P50 / P95 / P99，分接口）：
- 吞吐量（QPS / TPS）：
- 容量（并发用户 / 数据量）：
- 启动 / 加载时间：

## 安全（Security）
- 认证（登录方式 / 会话策略）：
- 授权（角色 / 权限模型）：
- 数据加密（传输 TLS / 存储加密）：
- 输入校验与防注入 / XSS / CSRF：
- 审计日志：
- 合规红线（PII / 支付 / 绝对化营销，回指 governance）：

## 可用性与可靠性（Reliability）
- 可用性目标（SLA，如 99.9%）：
- 灾备 / 故障恢复（RTO / RPO）：
- 降级方案（依赖不可用时产品如何表现）：
- 幂等与重试（资金链路必须，回指 engineer §8）：

## 兼容性（Compatibility）
- 平台（iOS / Android / Web / 桌面）：
- 浏览器版本范围：
- 屏幕尺寸 / 分辨率：
- 新旧版本共存（API 兼容策略）：

## 可访问性（Accessibility）
- 无障碍标准（WCAG 2.x AA？）：
- 键盘可达 / 读屏 / 对比度 / 字号：

## 可维护性与可扩展性（Maintainability）
- 日志与监控（关键指标采集）：
- 配置化 vs 硬编码（哪些需可配置）：
- 扩展预留（架构上为下一步留的口）：

## 数据合规（Data Compliance）
- 数据采集范围与最小化：
- 存储位置 / 加密 / 保留期限：
- 脱敏规则：
- 用户数据导出 / 删除权（GDPR / 个保法）：

## 验收方式（非功能如何验证）
- 性能压测（工具 / 目标）：
- 安全扫描（工具）：
