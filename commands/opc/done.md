当前岗位报完成。

**脚本**：`<skill包目录>/scripts/opc.py <子命令>`（`<skill包目录>` = 本 Skill 包所在目录，与宿主无关）。定位顺序：① 环境变量 `OPC_SKILL_DIR`；② 宿主注入的 skill 目录变量（指向包目录本身或其父目录）；③ 目录结构约定：`<本命令文件所在目录>/../../skills/opc-team/`（多数宿主把 `commands/` 与 `skills/` 放在同一配置根下）；④ 在工作区与用户主目录搜 `opc-team/scripts/opc.py`。用宿主可用的 Python 解释器以绝对路径调用。

**前置校验**

1. role 必须是本次 pm 派活清单里的岗位，否则命令会拒绝。
2. 本岗产出文件已按 `resolve` 得到的 URI 落盘，且已登记到 `30_项目/_产出索引.md`。

**步骤**

1. 执行 `done --role <role> [--project PXXX] [--file <附件>]`。
2. 汇报：资产快照、交接通知通道、当前挂起回执、下一棒角色（或「本次未派活，自动跳过」）。
3. 多岗位产出时追加 `--sync-self` 做本地入队；**不要直接碰远程仓库**。

**完成标准**：命令返回成功，产出快照与回执已生成，下一棒角色已明确。

**深入**：交接与通知 → 规范 §15.9；增量同步队列 → 手册 §36。
